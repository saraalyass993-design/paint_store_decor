# Paint Store Decor Management Module (Odoo 17)

A custom Odoo 17 module designed to streamline operations for paint and decoration stores, featuring advanced calculation tools and seamless user experience.

---

## 🌟 Features

- **Wall Coverage Calculator:** Easily calculate the required amount of paint and materials based on specific wall dimensions.
- **Product Category Filtering:** Advanced and efficient filtering system to help users and customers quickly find products by category.
- **Custom Backend Architecture:** Built with custom Python controllers, models, and views tailored specifically for Odoo 17.

---

## 🛠️ Technologies Used

- **Python** (Backend Logic)
- **XML** (Views & UI)
- **Odoo 17 Framework**

---

## 📦 Installation & Usage

1. Clone or copy the `paint_store_decor` folder into your Odoo `addons` directory.
2. Restart your Odoo server and enable **Developer Mode**.
3. Go to **Apps** > Click **Update Apps List**.
4. Search for `Paint Store Decor` and click **Install**.
